The scale: the parameter list looks short. What's hidden is that --pokemon accepts 1,024 species, --move accepts 938 moves, --ability accepts 311 abilities, and --question accepts 24 different kinds of question. Pick one from each and the interpreter generates 134.5 million possible English or Swedish sentences.

Two data layers

— merged into one answer

Every query hits two sources. The first is the same for everyone — official Pokédex data. The second is mine — a decade of collection data spread across four stores.

🌐 Pokédex

Static · external · shared · cached 5 min

  • pokedex.json — 1025 species, current gen
  • Types, weight, height, color, flavor text
  • Base happiness, catch rate, hatch cycles
  • Evolution chains — full graph, not just next stage
  • Learnsets per level, egg groups, hidden abilities
  • Cry URLs — latest and legacy
  • Locations, generation, species category
  • Move data — type, power, accuracy, PP, damage class
  • Legendary / mythical species flags

🎒 Collection

Mine · ~10,000 in Home · four sub-stores

  • shiny — IVs, ball, nature, style, ribbons per mon
  • specials — event-locked specimens, level-locked
  • events — event gifts with year and origin
  • breedables — per ball: possible, owned, HA, egg moves
  • 10,000 mons across a decade of play
  • Complete living shiny dex is the goal, not the status
  • Aprimon tracking — 1024 species × 11 ball types
  • Ribbon tracking on every shiny and special
The merge: when you ask "do I have bulbasaur with zero attack", the script checks shiny, specials, events, and breedables. If nothing matches the exact species, it walks evo_relatives — every evolution of bulbasaur — and reports the closest match instead of a plain "no". That fallback is why the answer sometimes surprises you.

5

Four things that make it work

— beyond the pattern matching
🧬

Evolution fallback

Ask about one species, get an answer about its whole line.

When no direct match exists for "charmeleon with 31 attack", the script walks evo_relatives — every ancestor and descendant — and reports the closest match. That's why the answer says "yes, your charizard" instead of a flat no.

Uses the full evolution graph from pokedex.evolutionSteps — not just the next stage.

⚡

Five-minute cache

nix eval is slow. The cache makes queries feel instant.

Every lookup runs nix eval $FLAKE.pokenix.$path and dumps the JSON into ~/.cache/pokenix/. A second query within 5 minutes reuses the file instead of re-evaluating the flake.

find "$f" -mmin +5 is the whole TTL. Simpler than it sounds.

🎙️

134.5M-phrase fuzzy match

912 patterns. 147,478 combinations. One typo-tolerant matcher.

Voice input goes through trigram_similarity and levenshtein_similarity, then find_best_fuzzy_match picks the winner above threshold = 0.5.

Swedish and English live side-by-side in the sentences array — the matcher doesn't care which one you used.

🔊

Cry playback

--question cry isn't a text response. It plays audio.

play_cry checks mpv, then ffplay, then vlc, and runs whichever one exists in the background. PokeAPI serves both latest and legacy cry URLs.

If nothing's installed, it returns non-zero with the URL in the error, so you can still hear it manually.

One small detail worth knowing: join_words is a tiny jq filter that turns ["a"] into a, ["a","b"] into a and b, and ["a","b","c"] into a, b and c. Every response that lists multiple items uses it — so the output reads like a sentence, not a comma dump.
