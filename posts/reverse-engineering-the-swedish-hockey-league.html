Step 1: Discover the API.

A curl against the league's public site, a URL for their internal API
buried in the .html, and another curl on that. I braced for
403 Forbidden. I got 200 OK. I checked again. Still 200. No
headers, no token in a cookie, no auth I could see. Just JSON, and decades of it, for the asking.

Quackly my hacker story turn into something entirely different...

Hats off to the Swedish Hockey League and their web administrators for keeping the statistics open and see-through allowing open source to push forward.

Step 3: Understand the league identifiers.

The ssgtUuid is not a secret in any meaningful sense. It isn't
even obfuscated - it sits in a query string in the page source,
unchanged for years. The layout-info endpoint lists one for every
season, series, and game type the league has ever played. The
regular-season SHL one for 2026 is qa98unlbd6. Both leagues
publish their own:

leagues 
ha  = {
  ssgtUuid = "uy2zvu6xaa";
  apiBase  = "https://www.hockeyallsvenskan.se/api";
};
shl = {
  ssgtUuid = "qa98unlbd6";
  apiBase  = "https://www.shl.se/api";
};
Heads up!

These are public endpoints serving public data. Don't hammer them,
don't redistribute the raw feed

Step 4: Build a reusable Nix configuration.

Rather than write multiple yo scripts, I wrote one unified builder and instantiated
it twice, once per league. I also decided to make one additional script exclusively for searching games.
Everything that differs between the leagues lives in a plain attrset.
Teans are defined outside of the league to avoid the need for manual entries each season.
Teams are also fuzzy matched for user friendly searches.

The interesting part is that Nix isn't just configuring two scripts here. It's generating the whole interface.

One attrset describes the league, its teams, API endpoints and identifiers. From that, the builder produces the scraper, team matching, API mappings, voice entities, parameters and sentence templates.

Same engine. Two leagues. duckPUCK

yo.scripts 
yo.scripts = {
  "duckPUCK-ha"    = mkDuckPUCK "ha"  leagues.ha;
  "duckPUCK-shl"   = mkDuckPUCK "shl" leagues.shl;
  "duckPUCK-games" = mkDuckPUCKGames;
};

Step 5: Define the parameters.

Every parameter here is what yo exposes to the caller and what the
voice layer fills in from natural language. mode is the only required
one - table, recent, upcoming, best, worst - and it is pulled
from a shared enum (swe.allowFrom) so the Swedish synonyms stay in
sync across scripts. team is the fuzzy-matched team name, stat is
the stat key (powerplay, tallest, goals, …), count is how many
rows to return, and dataDir is where the scraper writes table.json.

All of it is declared once per league, and the builder wires it into
the scraper, the analyzer and the voice parser. There is no second
place to keep in sync - which is the whole point of building this
as an attrset instead of two hand-written shell scripts.

So, these will be the valid parameters for stats:

  • powerplay

Step 6: Generate the voice vocabulary.

The vocabulary is where the project gets silly. Each entry in
sharedSentenceBodies is a Swedish phrase with placeholders for
{team}, {stat}, {mode} and {count}. The voiceTeamVals list
turns every alias - färjestad, farjestad, fbk - into a voice
entity, so the same team can be reached through any of its names.
Multiply roughly sixty sentence bodies by the team aliases, the
stat values, the mode values and the count values, and you land
around 88,000 recognisable phrases per league.

The Nix builder does this arithmetic at evaluation time: the
sentences list is map (s: "${league.voicePrefix} ${s}") sharedSentenceBodies,
and the lists are built from the same attrsets that drive the
scraper. One source of truth, two leagues, one voice prefix each.

Step 7: Turning raw statistics into spoken interpretation / analysis engine.

The assistant actually understands hockey context.

It doesn't simply read a table and announce the numbers.

It interprets league position and generates contextual commentary:


  • League leader.

  • Top-three contender.

  • Mid-table team.

  • Lower-half team.

  • Relegation-threatened team.

Then it adds goal difference, overtime performance and other observations.
The powerplay and boxplay analysis also evaluates league rankings and generates different commentary depending on performance.

Numbers into Swedish words, positions into ordinal words, useful for a good duckPUCK commentary.

  pyEnv = pkgs.python3.withPackages (ps: [ ps.requests ]);
  mkScraper = league:
    let
      teamMappingJson = builtins.toJSON (lib.mapAttrs (name: team: team.apiName) league.teams);
    in pkgs.writeScript "hockey-scraper-${league.key}.py" ''
      #!${pyEnv}/bin/python
      import os, re, json, logging, argparse
      import requests

      parser = argparse.ArgumentParser()
      parser.add_argument("--dataDir", type=str, required=True)
      args = parser.parse_args()
      os.makedirs(args.dataDir, exist_ok=True)
      table_path = os.path.join(args.dataDir, "table.json")
      logging.basicConfig(level=logging.INFO, format="[🦆🏒] %(levelname)s - %(message)s")
      logger = logging.getLogger()

      headers = {
          "User-Agent": "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.114 Safari/537.36",
          "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
          "Accept-Language": "en-US,en;q=0.5",
      }
      SSGT_UUID = "${league.ssgtUuid}"
      API_BASE  = "${league.apiBase}"
      TABLE_URL = "${league.tableUrl}"

      TEAM_MAPPING = ${teamMappingJson}

      def fetch(url):
          logger.info(f"Fetching {url}")
          try:
              r = requests.get(url, headers=headers, timeout=15)
              r.raise_for_status()
              return r.text
          except Exception as e:
              logger.error(f"Failed to fetch {url}: {e}")
              return None

      def fetch_powerplay_data():
          url = f"{API_BASE}/statistics-v2/stats-info/teams_powerplay?count=25&ssgtUuid={SSGT_UUID}&provider=statnet&state=active&moduleType=result"
          html = fetch(url)
          if not html:
              return {}
          try:
              data = json.loads(html)
              return {t['info']['siteDisplayName']: t.get('PPPerc', '?') for t in data[0]['stats']}
          except Exception as e:
              logger.error(f"Failed to parse powerplay: {e}")
              return {}

      def fetch_boxplay_data():
          url = f"{API_BASE}/statistics-v2/stats-info/teams_penaltyKilling?count=25&ssgtUuid={SSGT_UUID}&provider=statnet&state=active&moduleType=result"
          html = fetch(url)
          if not html:
              return {}
          try:
              data = json.loads(html)
              return {t['info']['siteDisplayName']: t.get('PKPerc', '?') for t in data[0]['stats']}
          except Exception as e:
              logger.error(f"Failed to parse boxplay: {e}")
              return {}

      def scrape_table():
          html = fetch(TABLE_URL)
          if not html:
              return []
          table_match = re.search(r'<table[^>]*class="[^"]*table[^"]*"[^>]*>(.*?)</table>', html, re.DOTALL)
          if not table_match:
              table_match = re.search(r'<table[^>]*>(.*?)</table>', html, re.DOTALL)
          if not table_match:
              return []
          rows = re.findall(r'<tr[^>]*>(.*?)</tr>', table_match.group(1), re.DOTALL)
          table_data, seen = [], set()
          for row in rows:
              cells = re.findall(r'<t[dh][^>]*>(.*?)</t[dh]>', row, re.DOTALL)
              if len(cells) < 11:
                  continue
              clean = []
              for cell in cells:
                  c = re.sub(r'<[^>]*>', "", cell)
                  c = re.sub(r'&nbsp;', ' ', c)
                  c = re.sub(r'\s+', ' ', c).strip()
                  clean.append(c)
              if not clean[0].isdigit() or not clean[1] or clean[1] in seen:
                  continue
              seen.add(clean[1])
              table_data.append({
                  "position":        clean[0],
                  "team":            clean[1],
                  "games_played":    clean[2],
                  "wins":            clean[3],
                  "ties":            clean[4],
                  "losses":          clean[5],
                  "overtime_wins":   clean[6],
                  "overtime_losses": clean[7],
                  "goals_for":       clean[8],
                  "goals_against":   clean[9],
                  "goal_difference": clean[10],
                  "points":          clean[11] if len(clean) > 11 else "0",
              })
              if len(table_data) >= 14:
                  break
          return table_data

      def main():
          logger.info("🏒 Starting ${league.name} scraper...")
          table_data = scrape_table()
          pp = fetch_powerplay_data()
          bp = fetch_boxplay_data()
          for team in table_data:
              api_name = TEAM_MAPPING.get(team['team'], team['team'])
              team['powerplay'] = pp.get(api_name, '?')
              team['boxplay']   = bp.get(api_name, '?')
          if table_data:
              with open(table_path, 'w') as f:
                  json.dump(table_data, f, ensure_ascii=False, indent=2)
              logger.info(f"Saved {len(table_data)} teams to {table_path}")
          else:
              logger.warning("No table data to save")
          logger.info("${league.name} scraping completed!")

      if __name__ == "__main__":
          main()
    '';



  mkFuzzyMatch = league:
    let
      teamCases = lib.concatStringsSep "\n"
        (lib.mapAttrsToList (name: team:
          "            ${lib.concatMapStringsSep "|" (a: "*${a}*") team.aliases}) echo \"${name}\"; return 0 ;;"
        ) league.teams);
    in ''
      fuzzy_match_team() {
        local input_team="$1"
        local table_file="$2"
        dt_debug "Fuzzy matching team: $input_team"
        local lowered
        lowered=$(echo "$input_team" | tr '[:upper:]' '[:lower:]')
        case "$lowered" in
          ${teamCases}
        esac

        # 🦆 says ⮞ fall back to fuzzy match against table teams
        local -a teams
        mapfile -t teams < <(jq -r '.[].team' "$table_file")
        local best_match=""
        local best_score=0
        local normalized_input
        normalized_input=$(normalize_string "$input_team")
        for team in "''${teams[@]}"; do
          local normalized_team
          normalized_team=$(normalize_string "$team")
          if [[ "$normalized_team" == *"$normalized_input"* ]] || [[ "$normalized_input" == *"$normalized_team"* ]]; then
            echo "$team"
            return 0
          fi
          local lev_score
          lev_score=$(levenshtein_similarity "$normalized_input" "$normalized_team")
          if (( lev_score > best_score )); then
            best_score=$lev_score
            best_match="$team"
          fi
        done
        if (( best_score >= 30 )); then
          echo "$best_match"
          return 0
        else
          dt_debug "No good fuzzy match (best: $best_match, score: $best_score%)"
          return 1
        fi
      }
    '';

        get_player_stats() {
          local stat_type="$1"
          local count="$2"
          local endpoint="$API_BASE/statistics-v2/stats-info/players_point"
          local params="count=100&sortKey=TP&ssgtUuid=$SSGT_UUID&provider=statnet&state=active&moduleType=point"
          local response
          response=$(curl -s "''${endpoint}?''${params}")
          if [ $? -ne 0 ]; then
            dt_error "Failed to fetch player data"
            return 1
          fi

          case "$stat_type" in
            "tallest"|"shortest")
              local sort_dir="desc"
              [ "$stat_type" = "shortest" ] && sort_dir="asc"
              echo "$response" | jq -r '
                .[0].stats |
                map(select(.info.height.value != null)) |
                sort_by(.info.height.value) |
                '"$( [ "$sort_dir" = "desc" ] && echo "reverse |" )"'
                .[0:'$count'] |
                .[] |
                "\(.Rank). \(.info.fullName) (\(.info.team.name)) - Längd: \(.info.height.value) \(.info.height.format)"'
              ;;
            "heaviest"|"lightest")
              local sort_dir="desc"
              [ "$stat_type" = "lightest" ] && sort_dir="asc"
              echo "$response" | jq -r '
                .[0].stats |
                map(select(.info.weight.value != null)) |
                sort_by(.info.weight.value) |
                '"$( [ "$sort_dir" = "desc" ] && echo "reverse |" )"'
                .[0:'$count'] |
                .[] |
                "\(.Rank). \(.info.fullName) (\(.info.team.name)) - Vikt: \(.info.weight.value) \(.info.weight.format)"'
              ;;
            "oldest"|"youngest")
              local sort_dir="asc"
              [ "$stat_type" = "youngest" ] && sort_dir="desc"
              echo "$response" | jq -r '
                .[0].stats |
                map(select(.info.birthDate != null)) |
                sort_by(.info.birthDate) |
                '"$( [ "$sort_dir" = "desc" ] && echo "reverse |" )"'
                .[0:'$count'] |
                .[] |
                "\(.Rank). \(.info.fullName) (\(.info.team.name)) - Född: \(.info.birthDate)"'
              ;;
            "goals"|"points"|"assists")
              local sort_key
              case "$stat_type" in
                "goals")   sort_key="G"  ;;
                "points")  sort_key="TP" ;;
                "assists") sort_key="A"  ;;
              esac
              local endpoint2="$API_BASE/statistics-v2/stats-info/players_point"
              local params2="count=$count&sortKey=$sort_key&ssgtUuid=$SSGT_UUID&provider=statnet&state=active&moduleType=point"
              response=$(curl -s "''${endpoint2}?''${params2}")
              # 🦆 says ⮞ FIX: use --arg for $stat and $k (was broken in HA original)
              echo "$response" | jq -r --arg stat "$stat_type" --arg k "$sort_key" '
                .[0].stats[] |
                "\(.Rank). \(.info.fullName) (\(.info.team.name)) - \($stat): \(.[$k])"'
              ;;
            "icetime")
              echo "$response" | jq -r '
                .[0].stats |
                map(select(.TOI_GP != null)) |
                sort_by((.TOI_GP | split(":") | (.[0]|tonumber)*60 + (.[1]|tonumber))) |
                reverse |
                .[0:'$count'] |
                .[] |
                "\(.Rank). \(.info.fullName) (\(.info.team.name)) - Istid: \(.TOI_GP) per match"'
              ;;
            "shorthanded")
              echo "$response" | jq -r '
                .[0].stats |
                sort_by(-.SHTP) |
                .[0:'$count'] |
                .[] |
                "\(.Rank). \(.info.fullName) (\(.info.team.name)) - Boxplay poäng: \(.SHTP)"'
              ;;
            *)
              dt_error "Unknown stat type: $stat_type"
              return 1
              ;;
          esac
        }
