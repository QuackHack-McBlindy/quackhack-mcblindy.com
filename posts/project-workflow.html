PRE-FLIGHT (exit 1 on failure)
  │ -->  flake.lock exists · has history · age ≤ 14 days
  │ --> confirm "HAVE YOU COMMITED THE WORD?"
  │ --> branch == dev · latest vX.Y.Z tag exists
  │ --> flake exposes ≥1 package for x86_64-linux · all valid semver
  │ --> strict majority version exists (>50%, no ties)
  │ --> majority == latest tag + 1 patch
  │ --> dev merges cleanly with origin/main
  │ --> CHANGELOG [Unreleased] non-empty
  ▼
RELEASE ACTIONS
  │  --> rebase onto origin/dev · push empty commit if no changes
  │  --> push dev
  │  --> reuse open dev→main PR, else create (body = CHANGELOG [Unreleased])
  │  --> poll ≤5 min for CI check-runs on HEAD
  │  --> gh pr checks --watch --fail-fast
  │  --> verify PR MERGEABLE (retry while UNKNOWN)
  │  --> gh pr merge --merge
