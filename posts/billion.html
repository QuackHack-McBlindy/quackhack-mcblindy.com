What a billion actually means

yo do is a natural language to shell script translator. You speak or type a sentence. It runs exact and fuzzy pattern matching against a set of templates, resolves the parameters, and executes the corresponding script. No command list to memorize. No aliases to look up. Just a sentence.

A billion is easy to say and hard to picture. So let's make it concrete.

The math

yo do doesn't have a billion sentences written into it. It has 8,043 patterns — human-written templates with slots. What turns those 8,043 patterns into 1,070,236,143 phrases is the parameter space.

Every slot in a pattern can be filled by every value that slot accepts. When a pattern says "deploy {host}" and {host} can be any of your machines, that's one pattern generating many sentences. When a pattern says "what {question} is {pokemon}" and {question} has 24 values and {pokemon} has 1,024, that's one pattern generating 24,576 sentences.

Stack enough slots across enough scripts, and the multiplication does what multiplication does. 8,043 patterns × ~133,064 variations per pattern = over a billion distinct sentences the runtime matcher recognizes.

Wildcards aren't counted. A slot like {eggMoves.wildcard = true} accepts any value, not a fixed list — so it can't be enumerated. The 1.07 billion is therefore a lower bound on what yo do understands, not an upper one. Wildcard slots push the real reach further past a billion than the counted number does.

The number isn't the interesting part

Plenty of tools can generate a billion strings. A billion is trivial to fake — "repeat the word quack one billion times" is a one-line script and also meaningless. What makes this milestone different is what the number represents.

  • Every phrase is a real, resolvable command. If you say it (or type it), yo do finds the script that matches, resolves the parameters, and executes it. Nothing in that billion is theoretical. The phrase count is a lower bound on the set of actually understandable inputs — not the set of parseable ones.
  • It's parameter variations, not sentence variations. A billion ChatGPT prompts would be a billion sentences. A billion yo do phrases is a much smaller set of sentence shapes with every meaningful combination of slots filled in. That's why it works: the system doesn't need to have seen your exact sentence. It needs to recognize your sentence as belonging to a pattern it does understand, then read the parameters out of it.
  • Natural language, not command syntax. These are the phrases you'd actually say out loud. "Do I have bulbasaur shiny." "Deploy homie." "Which move is flamethrower." "How many shinies do I have left." The billion is the count of those — not of yo pokemon --pokemon bulbasaur --shiny true.

What understandable means here

The phrase count only includes sentences that pass three tests:

1

Pattern match

Exact or fuzzy — the sentence has to resolve to one of the 8,043 templates. Fuzzy matching handles typos and slight rephrasing, but it does not invent understanding where none exists.

2

Parameter resolution

Every slot in the matched pattern has to resolve to a valid value from that slot's allowed set. "Deploy ducklett" fails at this step because ducklett isn't a host. "Deploy homie" succeeds because homie is.

3

Script execution

The resolved parameters have to actually run. A pattern that matches but produces a script that errors is not a phrase that "works" — it's a phrase that fires the wrong thing, which is worse than not matching at all.

So the billion is not "sentences the system will attempt." It's "sentences the system will correctly recognize, resolve, and run." That's a much smaller, much more honest number.

Why it took a while

Eight thousand patterns is a lot to hand-write. A hundred thousand phrases per pattern is a lot of grammar to get right — genders, plural forms, word order, Swedish and English, synonyms, optional words, abbreviations. Every new pattern multiplies against every existing parameter list, and every new parameter value multiplies against every existing pattern. The phrase count grows quadratically, but the work to keep it accurate grows with both sides.

That's what hitting one billion really means: not that the matcher is fast — 97 ms average across 1,467 runs is nice but cheap — but that the vocabulary underneath it is dense enough. 1,024 Pokémon. 938 moves. 311 abilities. Every host, every ball, every stat, every question kind. The multiplication naturally clears a billion.

And it helps that 70 of the 100 scripts expose their vocabulary to the voice layer. Those 70 are the scripts that can be spoken to, and they're what feeds the phrase count. The other 30 are infrastructure — hooks, generators, helpers — that nobody needs to say out loud.

The system is not smart. It's thorough.
And thorough, at this scale, is its own kind of milestone.
