Yo

Plattform: NixOS flake

A deterministic voice‑command framework. Define scripts with parameters, write sentence patterns, and compile them into a blazing‑fast command index. Execute via text or speech — no LLM, no guessing, just rules you control at zero latency.
Compile-time fuzzy sentence conflict detection means every deployment is tested and production ready.

⚡

Blazing Fast

Pre‑compiled indexes & priority‑ordered exact matching.
Top speed at approx 0,1 ms.

🧠

Deterministic

Rule‑based, not probabilistic. No LLM, no hallucinations — just the commands you define.

💥

Huge Phrase Coverage

Expand a single script into hundreds of thousands of possible sentences.

🛡️

Compile‑Time Safety

Conflict detection catches overlapping sentences before you deploy. Fuzzy near‑conflicts too.
Parameter validation by default.

❄️

NixOS Native

Reproducible and deployable from a single flake input.

📦

Embeddable

Lightweight Rust runtime + ESP32 library (yo‑esp) for tiny devices. After setup 100% offline.
